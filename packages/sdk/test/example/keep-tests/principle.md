# Keep the tests

Do not delete a test to make a change pass; fix the code, or change the test on purpose.

A failing test is information.
Removing it hides the failure from the next person instead of fixing it.
When a test is wrong, say why in the change that rewrites it, and keep what it checked if that still matters.
When the behaviour it covered is gone for good, delete it together with that behaviour and say so.
