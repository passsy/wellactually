# Running the review in OpenCode

Start each step with the task tool, the `general` subagent and the prompt the step gives.
A subagent runs with the model OpenCode gives it, so every step runs with that model, the cheap steps included.
Start the subagents of one step at the same time, and wait for all of them before the next step.

When you have no task tool, follow `pi.md` instead.
